# projetoI.Aresponde
Assistente de IA para Documentos: Sistema Q&amp;A em Python que utiliza Inteligência Artificial para responder a perguntas baseando-se exclusivamente em PDFs locais. Usa a arquitetura RAG para garantir precisão e evitar alucinações. Tecnologias principais: LangChain, OpenAI, ChromaDB e PyPDF.
